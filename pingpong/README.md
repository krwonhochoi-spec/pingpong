# 🏓 암사동 탁구사랑 클럽 — 연동 및 배포 가이드

윤아 할머니·할아버지 전용 **탁구 경기 결과 기록 앱** (갤럭시 폰 최적화). 프론트엔드는 GitHub Pages, 데이터는 Google Sheets(Apps Script 웹 앱)에 저장합니다.

> 경기 방식: **10세트 선승 (최대 19세트)**. 각 세트 점수는 실물 스코어보드로 관리하고, 앱에는 **최종 세트 스코어만** 기록합니다. 입력은 **10 : 10에서 시작**하므로 진 쪽 세트 수만 내리면 됩니다.

> **v3 (2026-10-14) 실시간 동기화**: 한 폰에서 세트 스코어를 바꾸면 다른 폰 화면에 **약 2~3초 내** 반영됩니다. 저장·수정·삭제도 자동 반영. ⚠️ 적용하려면 **`Code.gs` 재배포(새 버전)** + **`index.html`·`sw.js` GitHub 업로드** 둘 다 필요합니다.

> **v4 (2026-10-17) 경기일 자동 표기**: 결과 입력의 경기일이 항상 **오늘**로 자동 표시됩니다(앱 실행·화면 켜짐·자정 경과·경기 저장 후). '어제' 등으로 바꾼 날짜는 그날 저장 전까지만 유지됩니다. `index.html`·`sw.js`(캐시 v9) 업로드 필요, `Code.gs` 변경 없음.

## 파일 구성

| 파일 | 용도 |
|---|---|
| `index.html` | 앱 전체 (HTML + Tailwind CDN + Chart.js + Vanilla JS, 캐릭터 SVG 내장) |
| `manifest.webmanifest` | 홈 화면 앱 설치 정보 (이름·아이콘·전체화면) |
| `sw.js` | 서비스 워커 (오프라인 실행, 빠른 로딩) |
| `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` | 앱 아이콘 |
| `Code.gs` | Google Apps Script 백엔드 (조회/추가/수정/삭제 + 실시간 상태) — GitHub 업로드 불필요 |
| `README.md` | 본 가이드 |

> 시트 연결 전에도 앱을 열면 **샘플 데이터 + 폰 내부 저장(LocalStorage)** 모드로 바로 동작합니다. 이 상태에서는 두 폰이 **공유되지 않습니다**.

## 1. Google Sheets + Apps Script 설정

1. [Google Sheets](https://sheets.new)에서 새 스프레드시트 생성 (이름 예: `암사동 탁구사랑 클럽`).
2. 메뉴 **확장 프로그램 → Apps Script** 클릭.
3. 기본 `Code.gs` 내용을 모두 지우고, `Code.gs` 전체를 붙여넣은 뒤 💾 저장.
4. 함수 선택에서 **`setup`** → **실행** (최초 1회 권한 승인: 계정 선택 → "고급" → "이동(안전하지 않음)" → 허용). `Workouts` 탭과 헤더가 자동 생성됩니다.
5. (선택, 권장) **API 토큰**: `setApiToken` 함수 안 문자열을 원하는 비밀번호로 바꾸고 실행 → 앱 설정의 'API 토큰'에 같은 값 입력.

### 웹 앱 배포

1. **배포 → 새 배포** → 유형 **웹 앱**.
2. **실행 계정: 나** / **액세스 권한: 모든 사용자** ← 반드시 이 값.
3. **배포** → 웹 앱 URL(`https://script.google.com/macros/s/……/exec`) 복사.

### `Code.gs`를 수정한 경우 (v3 업데이트 포함) — 필수

1. Apps Script 편집기에 새 `Code.gs` 전체 붙여넣기 → 💾 저장.
2. **배포 → 배포 관리 → ✏️(편집) → 버전: 「새 버전」 → 배포**.
   - 「새 배포」를 누르면 URL이 바뀝니다. 반드시 **배포 관리 → 편집**으로 해야 기존 URL이 유지됩니다.
   - 저장만 하고 재배포하지 않으면 웹 앱은 **이전 코드로 계속 동작**합니다.
3. (권장) 함수 `setup`을 한 번 실행.
4. 앱 ⚙️ 설정 → **🔌 연결 테스트** → `🟢 실시간 공유 지원 (Code.gs v3)` 표시 확인.

### 시트 컬럼 (`Workouts`)

| 컬럼 | 설명 |
|---|---|
| `id` | 고유 식별자 |
| `date` | 경기 날짜 `YYYY-MM-DD` |
| `type` | `pingpong` |
| `winner` | `husband`(윤아 할아버지) / `wife`(윤아 할머니) / `draw` — 세트 수로 자동 계산 |
| `husband_sets`, `wife_sets` | 최종 세트 수 (예: 7, 10) |
| `set_Diff` | `husband_sets − wife_sets` (자동 계산) |
| `memo` | 한줄 메모 |
| `updated_at` | 최종 수정 시각 |
| `score_detail`, `duration_min`, `calories`, `distance_km`, `participant` | **미사용** (빈값). 기존 스키마 호환을 위해 열만 유지 |

- 시트에 예전 달리기·자전거 행이 남아 있어도 앱은 **탁구 행만** 표시합니다(시트 원본은 그대로 유지).
- 시트에서 직접 수정·삭제해도 `onEdit` 트리거가 변경번호를 올려 앱에 자동 반영됩니다.
- 진행 중 세트 스코어와 변경번호는 시트가 아닌 **스크립트 속성**(`LIVE_STATE`, `DATA_REV`)에 저장됩니다.

## 2. 두 폰 연결 (가장 중요)

**두 폰 모두** 같은 웹 앱 URL(+토큰)이 입력되어 있어야 공유됩니다. 한 폰이라도 `📱 로컬`로 표시되면 그 폰은 공유되지 않습니다.

1. 첫 번째 폰: **⚙️ 설정 → Google Sheets 연동** → URL(+토큰) 입력 → **🔌 연결 테스트** → **설정 저장**.
2. 같은 화면에서 **📲 상대방 폰 연결 링크 보내기** → 카카오톡/문자로 상대방에게 전송.
3. 두 번째 폰: 받은 링크를 열고 **연결** 누르기 → URL·토큰이 자동 입력됩니다.
4. 두 폰 상단 칩이 모두 **🟢 실시간**이면 완료.

### 동기화 동작

| 항목 | 방식 |
|---|---|
| 진행 중 세트 스코어(결과 입력 화면) | 변경 즉시 서버로 전송 → 상대 폰이 3초마다 조회해 반영 (상대방 변경 시 숫자가 노랗게 깜빡임) |
| 경기 저장 | 저장한 폰은 입력판이 10:10으로 초기화되고, 상대 폰도 함께 초기화 + "상대방 폰에서 경기 결과를 저장했습니다" 안내 → 중복 저장 방지 |
| 저장·수정·삭제된 기록 | 시트 변경번호가 바뀌면 상대 폰이 전체 재조회 (약 3~8초) |
| 조회 주기 | 결과 입력 탭 3초 / 통계·기록 탭 8초 / 오류 시 10초 / 화면 꺼짐·백그라운드 시 중단 |
| 동시 입력 | 마지막 입력 우선 (같은 세트 수를 두 사람이 동시에 바꾸면 나중 입력값이 남음) |
| 오프라인 | 저장·삭제는 대기열에 보관 → 연결 복구 시 자동 전송. 대기 중에도 상대방 변경분은 계속 수신 |
| 구버전 `Code.gs` | 진행 중 점수 공유 불가, 저장된 기록만 20초마다 재조회 (칩 `☁️ 연결됨`) |

## 3. GitHub Pages 배포

1. GitHub에서 새 저장소 생성 (예: `pingpong`, Public).
2. `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` 6개 파일 업로드.
3. **Settings → Pages → Deploy from a branch → main / (root) → Save**.
4. 1~2분 후 `https://<아이디>.github.io/pingpong/` 접속.

### 갤럭시 폰에 앱처럼 설치

- **삼성 인터넷**: 주소창의 ⬇(설치) 아이콘 또는 **≡ 메뉴 → 현재 페이지 추가 → 홈 화면**.
- **Chrome**: 앱 상단 **📲 설치** 버튼, 또는 **⋮ → 홈 화면에 추가 → 설치**.
- 홈 화면의 🏓 **탁구사랑 클럽** 아이콘으로 실행하면 전체화면으로 열립니다.
- 업데이트: GitHub에 새 파일 업로드 후 **두 폰 모두** 앱을 완전히 종료(최근 앱에서 밀어 닫기) 후 다시 실행. 칩에 `🟢 실시간`이 보이면 새 버전입니다.

## 4. 화면 구성

- **승리 캐릭터 캘린더**: 경기한 날에는 날짜 대신 그날 승자 캐릭터 표시(하루 여러 경기면 승수 → 세트 득실 순으로 판정, 동률은 🤝, 2경기 이상은 ×2 표시). 날짜를 누르면 그날 경기 조회·수정·삭제·추가. 좌우 밀기로 월 이동.
- **결과 입력** (할머니 왼쪽 / 할아버지 오른쪽):
  1. 날짜는 **오늘로 자동 표시** (필요 시 어제 버튼·달력으로 변경, 오늘이 아니면 노란 경고 표시)
  2. **10 : 10**에서 진 쪽의 **−** 버튼으로 세트 수 조정 (또는 큰 숫자를 눌러 0~10 선택표)
  3. **💾 저장 · 할머니 승 10 : 7** — 승자·세트 차이 자동 계산
  - 동점은 저장 불가. 10세트 전에 끝난 경기는 "미완료 경기" 확인 후 저장 가능
  - 입력판 아래 `🟢 두 폰 실시간 공유 중 · 상대방 변경 HH:MM:SS` 표시
- **통계**: 지난 10전/30전 승률, 경기 빈도(평균 인터벌), 평균 세트 차이, 이번 달 경기 수·전적, 현재 연승, 최다 연승, 승률 추이 그래프, 세트 차이 그래프.
- **기록 관리**: 월별 조회, 수정·삭제, 지난 경기 소급 입력, JSON 백업/가져오기, CSV 내보내기.
- **갤럭시 편의**: 홈 화면 설치·전체화면, 뒤로가기 버튼으로 창 닫기, 숫자 키패드, 진동 피드백, 폴드·태블릿 대응.

## 5. 문제 해결

| 증상 | 조치 |
|---|---|
| 상대 폰에 점수가 안 넘어감 | ① 두 폰 칩이 모두 `🟢 실시간`인지 확인 (`📱 로컬`이면 URL 미입력 → 2장 연결 링크 사용) ② `☁️ 연결됨`이면 `Code.gs` 구버전 → 1장 「Code.gs를 수정한 경우」대로 **새 버전 재배포** ③ 두 폰의 URL이 **완전히 같은지** 확인 |
| 칩이 `⚠️ 실패` | 칩을 눌러 오류 확인. 대부분 네트워크 일시 오류 → 자동 재시도 |
| `네트워크/CORS 오류` | 웹 앱 액세스 권한 **모든 사용자** 확인, URL이 `/exec`로 끝나는지 확인 |
| `인증 실패: API 토큰 불일치` | 두 폰 앱 설정 토큰 = 스크립트 속성 `API_TOKEN` |
| 코드 수정이 반영 안 됨 | Apps Script **배포 관리 → ✏️ → 새 버전**으로 재배포 / 폰 앱 완전 종료 후 재실행 |
| 경기일이 어제 날짜로 표시됨 | `index.html`(v4)·`sw.js`(캐시 v9) 업로드 여부 확인 후 두 폰 앱 완전 종료·재실행 |
| 시트 반영 제외 N건 안내 | 날짜 형식 오류 등 해당 건만 제외되고 나머지는 정상 저장됨 |
| 그래프 미표시 | 인터넷 연결 확인 (Chart.js CDN) |
| 📲 설치 버튼이 안 보임 | 이미 설치됨, 또는 manifest·sw·아이콘 파일 미업로드 → 브라우저 메뉴 "홈 화면에 추가" 사용 |
| 화면 색이 이상함(삼성 인터넷) | 설정에서 "웹페이지에 다크 모드 적용" 해제 |

### Apps Script 할당량 참고

- 화면이 켜진 동안만 조회하며(결과 입력 탭 3초 주기), 한 번의 조회는 스크립트 속성 1회 읽기입니다.
- 일반 Google 계정 기준 1일 할당량 내에서 하루 수 시간 사용에 문제없는 수준입니다. 참고: [Apps Script 할당량](https://developers.google.com/apps-script/guides/services/quotas)
