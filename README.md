# 탁구사랑 (건강지키미 + 탁구사랑클럽) — 전체 자료 v1.16

폴더 이름 `takgu-sarang-1.16` (빌드 도구 호환을 위해 영문)

작성일 2026-11-19 · 앱 버전 1.16 (versionCode 17) · 패키지 `kr.family.healthguard`

이 폴더 하나에 앱 설치 파일, 화면 소스, 갤럭시 앱 소스, 탁구사랑클럽 원본, 빌드 스크립트가 모두 들어 있다.
**서명키는 보안상 별도 파일(`탁구사랑-서명키.zip`)로 분리**했다. 앱을 업데이트하려면 이 두 묶음이 모두 필요하다.

## 2. 데이터는 어디에 있나

| 데이터 | 저장 위치 | 백업 방법 |
|---|---|---|
| 체중·혈압·맥박·산소포화도·운동·생활·일지·기념일 | **각 휴대폰 안**(앱 내부 저장소) | 앱 → 설정 → 데이터 보관 → **백업 파일 저장** (월 1회 권장) |

| 시트 연결 열쇠(웹 앱 URL·토큰) | 각 휴대폰 탁구 화면 설정 | 탁구 탭 → ⚙️ → **📲 상대방 폰 연결 링크 보내기** |

이 자료 묶음에는 **기록 자체는 들어 있지 않다.** 기록은 위 방법으로 따로 백업해야 한다.

## 3. 휴대폰에 설치·업데이트

1. `apk/탁구사랑-1.16.apk` 를 휴대폰으로 옮겨 누른다.
2. **'업데이트'** 버튼이 나오면 누른다 → 기존 기록 유지.
3. 처음 설치하는 휴대폰은 '설치'로 나온다(정상).
4. 기존 앱을 **먼저 지우고 설치하면 기록이 사라진다.** 절대 지우지 말 것.

옛 탁구사랑클럽(크롬 설치본)에서 옮기는 절차는 7절 참고.

## 5. 새 버전 만드는 법 (개발자용)

**필요 환경**: Ubuntu 22.04/24.04 또는 Windows WSL Ubuntu

```bash
sudo apt install -y openjdk-21-jdk-headless aapt zipalign apksigner dalvik-exchange libandroid-23-java nodejs npm python3 zip
# 1) 서명키 묶음을 이 폴더 안에 풀기 → takgu-sarang-1.16/signing/healthguard-release.jks, ks-pass.txt
# 2) 빌드 도구 설치(최초 1회)
cd android && npm ci
# 3) 버전 번호 올리기: AndroidManifest.xml 의 versionCode(현재 17)·versionName(현재 1.16)과
#    src/…/MainActivity.java 의 version() 반환값을 함께 수정
# 4) 빌드
VCODE=17 VNAME=1.16 ./build.sh          # 결과: android/out/healthguard.apk
```

- 이 스크립트로 다시 빌드하면 `apk/탁구사랑-1.16.apk` 와 **내용이 똑같은 APK**가 나오는 것을 확인했다(2026-11-09).
- 빌드는 `web/` 화면과 `pingpong/` 탁구 화면을 앱 안에 복사해 넣는다. 탁구 화면을 GitHub에서 고쳤다면 `pingpong/` 폴더를 최신 파일로 바꾼 뒤 빌드한다(또는 `PP=다른경로 ./build.sh`).
- 탁구 화면 원본은 고치지 않는다. 빌드할 때 복사본에만 다음을 손본다: 차트·스타일 파일을 앱 안에 넣어 인터넷 없이 열리게 하고, 연결 링크를 Pages 주소 기준으로 만들고, 파일 저장·링크 복사는 앱 기능을 쓰게 하고, 연결 링크를 받으면 바로 연결 창이 뜨게 한다.
- **같은 서명키로 서명해야** 휴대폰에서 '업데이트'가 되고 기록이 유지된다. 인증서 SHA-256: `4132c7ae…07d0c58`

## 7. 옛 탁구사랑클럽(크롬 설치본)에서 옮기기 — 요약

1. 옛 앱 → ⚙️ → **⬇️ JSON 백업**, 시트 연결이면 **📲 상대방 폰 연결 링크 보내기** → 카카오톡 '나와의 채팅'
2. 건강지키미 → 설정 → **백업 파일 저장**
3. `탁구사랑-1.16.apk` 설치('업데이트' 확인)
4. 새 앱 **기록** 탭에서 옛 기록 확인
5. 설정 → **탁구사랑클럽 연결** → 링크 붙여넣기 → **연결 링크 적용** → '연결'
   (로컬 기록이었다면: 탁구 탭 → **샘플 삭제** → ⚙️ → **⬆️ JSON 가져오기**)
6. 탁구 달력·운동 탭 '탁구 n일 × 80분' 확인
7. 옛 앱 삭제(아래 5칸 메뉴가 **없는** 탁구 아이콘. 앱 정보에서 '버전 1.16'이 아닌지 확인)
8. 사모님 휴대폰도 같은 순서

## 8. 보안 주의

- **이 폴더를 공개 GitHub에 그대로 올리지 말 것.** `web/app.js` 112행 `DEFAULT_ANNIV` 에 가족 생일·호칭이 들어 있다. 공개하려면 이 목록을 비우고, 기념일은 앱의 '기념일 파일 불러오기'로 넣는다.
- **서명키 묶음은 이 폴더와 따로 보관**(USB·개인 클라우드 2곳 이상). 서명키를 잃어버리면 기존 앱을 업데이트할 수 없어, 기록을 백업한 뒤 새 앱을 다시 설치해야 한다.
- 탁구 시트 열쇠(토큰)는 이 자료에 없다. 구글 Apps Script의 스크립트 속성 `API_TOKEN` 에 있다.
