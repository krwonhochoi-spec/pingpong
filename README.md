# 탁구사랑 (건강지키미 + 탁구사랑클럽)

부부가 각자 휴대폰에서 쓰는 개인 건강 기록 앱(갤럭시용). 체중·BMI, 혈압·맥박·산소포화도, 운동, 기념일을 기록하고, 탁구사랑클럽(탁구 스코어보드)을 앱 안에 함께 넣었음. 두 휴대폰의 데이터는 서로 연동하지 않음.

- 현재 버전: **1.14** (versionCode 15) · 패키지 `kr.family.healthguard`
- 설치 파일(APK)은 저장소에 넣지 않고 **Releases** 에 올림

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `web/app.html`, `web/app.js` | 앱 화면 전체(HTML·CSS·JavaScript). 안드로이드 앱과 웹 버전이 같은 파일을 씀 |
| `web/build_web.py` | 웹 버전 한 파일(`web/dist/health.html`) 만들기 |
| `android/` | 안드로이드 껍데기(WebView): `AndroidManifest.xml`, `src/…/*.java`, `res/`(아이콘), `build.sh`, `package.json` |
| `pingpong/` | 탁구사랑클럽 원본 사본(`krwonhochoi-spec/pingpong` 커밋 4e18748). 빌드할 때 앱 안에 복사됨 |
| `.gitignore` | 서명키·가족 정보·빌드 결과물이 실수로 올라가지 않도록 막는 목록 |

## 저장소에 올리지 않는 것 (중요)

| 파일 | 이유 | 보관 위치 |
|---|---|---|
| `signing/healthguard-release.jks`, `signing/ks-pass.txt` | 앱 서명키·비밀번호. 유출되면 다른 사람이 '업데이트'로 위장한 앱을 만들 수 있음 | 서명키 zip(별도 보관) |
| `private/anniv.js` | 가족 생일·기념일 기본값 | 개인자료 zip(별도 보관) |
| `*.apk` | 설치 파일 | GitHub Releases 또는 개인 보관 |

- 공개 저장소용 `web/app.js` 는 `const DEFAULT_ANNIV = [];` 로 비어 있음. 빌드할 때 `private/anniv.js` 가 있으면 자동으로 채워 넣음(없으면 기념일 기본값 없이 빌드됨).
- 탁구사랑클럽 연결 링크(`#gas=…&tk=…`)에는 시트 토큰이 들어 있으므로 저장소·이슈·README 어디에도 붙여 넣지 않음.

## 빌드 (개발자용)

Ubuntu 22.04/24.04 또는 Windows WSL Ubuntu 기준.

```bash
sudo apt install -y openjdk-21-jdk-headless aapt zipalign apksigner dalvik-exchange libandroid-23-java nodejs npm python3 zip
# 저장소 폴더 바로 아래에 signing/ 과 private/ 를 풀어 둠 (두 폴더는 .gitignore 로 제외됨)
cd android && npm ci                     # 최초 1회
VCODE=15 VNAME=1.14 ./build.sh           # 결과: android/out/healthguard.apk
cd ../web && python3 build_web.py        # 결과: web/dist/health.html
```

- 저장소 폴더 경로에 한글이 있으면 빌드 도구가 실패함. 영문 폴더(예: `takgu-sarang`)에서 실행하고 `export LC_ALL=C.UTF-8` 를 설정함.
- 새 버전을 낼 때는 `android/AndroidManifest.xml` 의 versionCode·versionName 과 `MainActivity.java` 의 `version()` 반환값을 함께 올림.
- **같은 서명키로 서명해야** 휴대폰에서 '업데이트'가 되고 기록이 유지됨. 인증서 SHA-256 `4132c7ae…07d0c58`.
- 이 저장소 + `signing/` + `private/` 로 빌드하면 배포된 1.14 APK와 내용(서명 제외 397개 항목)이 같음을 확인함(2026-11-10).

## 판정·계산 기준 (근거)

| 항목 | 기준 |
|---|---|
| BMI 6단계 | 대한비만학회 비만 진료지침 2022(8판) |
| 혈압 분류 | 대한고혈압학회 고혈압 진료지침 2022, 표 1 |
| 가정혈압 기준 | 135/85 mmHg |
| 맥박·산소포화도 정상 범위 | 60~100회/분 · 95~100% |
| 운동 권장량 | WHO 2020 신체활동 지침, 주 150~300분(중강도) |
| 운동 강도(MET) | 2024 Adult Compendium of Physical Activities. 철봉 매달리기(1회 시간만 기록): 매달리기 전용 코드가 없어 체조 코드 02024(가벼움 2.8)·02022(보통 3.8, 턱걸이 포함)·02020(힘듦 7.5) 적용(근사), 실외자전거 4.3/7.0 (01015/01014), 골프연습 3.5 (15270), 슬로우조깅 3.3/7.5 (12026/12020), 실내요가 2.3/2.7/4.0 (02150/02185/02160), 걷기 3.0/3.8/4.8 (17170/17190/17200, 분당 100보 환산), 스트레칭 2.3 (02101, 입력은 번 단위, 1번 30초 환산), 탁구 4.0 (15660) |
| 탁구 운동 시간 | 경기한 날 하루 80분으로 계산 |
| 음력 변환 | 1990~2049년 표 내장(한국천문연구원 기준 라이브러리로 생성, 대조 오차 0건) |
